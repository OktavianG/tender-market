# Tender Market

Расширяемый инструмент для поиска и исследования государственных и коммерческих закупок.

Проект первоначально создавался для анализа спроса на изделия из пластмасс, но не ограничен этой тематикой. Список ключевых слов и правила классификации можно изменить для поиска оборудования, запасных частей, строительных материалов, металлических изделий, упаковки, услуг и других предметов закупки.

## Возможности

- поиск по настраиваемым ключевым словам;
- выбор регионов, периода и глубины поиска;
- закупки по 44-ФЗ и 223-ФЗ;
- подключение коммерческих площадок независимыми адаптерами;
- удаление повторяющихся закупок;
- извлечение товарных позиций, количества, цены, суммы и ссылки;
- классификация результатов;
- Excel-отчёт со сводками по товарам, ОКПД2 и заказчикам;
- кэширование страниц и ограничение частоты запросов.

## Поддерживаемые источники

- ЕИС — закупки по 44-ФЗ и 223-ФЗ;
- Tender.Pro — экспериментальный адаптер открытых коммерческих процедур.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка поиска

Ключевые слова находятся в `SEARCH_QUERIES` файла `main.py`:

```python
SEARCH_QUERIES = [
    "пластмассовый",
    "пластиковый",
    "заглушка пластиковая",
    "втулка пластиковая",
]
```

Их можно заменить под другую отрасль:

```python
SEARCH_QUERIES = [
    "насос промышленный",
    "компрессор",
    "редуктор",
    "запасные части оборудования",
]
```

Регионы, период, число страниц и безопасный лимит карточек также задаются в начале `main.py`.

## Запуск

```bash
python main.py
```

По завершении программа создаёт `plastics_tenders.xlsx` с листами:

- `Целевые изделия`;
- `Проверить`;
- `Все позиции`;
- `Сводка по товарам`;
- `Сводка ОКПД2`;
- `Заказчики`.

Имя итогового файла можно изменить в настройках.

## Архитектура

Каждая коммерческая площадка подключается отдельным модулем в `sources/`. Изменение одного сайта не должно затрагивать общую классификацию, Excel-отчёт или остальные источники.

## Статус

Проект находится в экспериментальной разработке. Парсер ЕИС работает, интеграция Tender.Pro проходит тестирование. Площадки могут изменять структуру страниц, правила доступа и ограничения частоты запросов.

## Ответственное использование

Используйте только открытые данные. Соблюдайте правила площадок и разумные интервалы между запросами. Проект не предназначен для обхода авторизации, блокировок, CAPTCHA или других технических ограничений.
